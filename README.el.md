**Ένα SonnerStudio fork του [Hermes Agent](https://hermes-agent.nousresearch.com/) από το Nous Research** — ο αυτοβελτιούμενος πράκτορας AI, επεκταμένος με μια φωνητικά ελεγχόμενη **Hermes Γραμματέας** και ένα οπτικό **Composer-Control-HUD** για τον συντονισμό υπο-πρακτόρων.

Αυτό το fork προσθέτει:

- **Composer Control Buttons** — τέσσερα κουμπιά εναλλαγής στο επιτραπέζιο composer με χρώματα κατάστασης σε πραγματικό χρόνο (κόκκινο = ανενεργό, κίτρινο = provisioning, πράσινο = ενεργό) :
  1. **Ενεργοποίηση sub-agents** — ενεργοποιεί τα εξειδικευμένα AI sub-agents που αναλαμβάνουν ανεξάρτητα υπο-εργασίες, το καθένα με τις δικές του εξειδικευμένες ικανότητες, και μαθαίνουν συνεχώς από εργασίες και με το χρόνο. Όταν η Γραμματέας είναι **απενεργοποιημένη**, η ομάδα εργάζεται αυτόνομα: αναλαμβάνει μόνη της εργασίες από τον Hermes Agent (χαμηλότερο όριο παραλληλισμού, διπλό προϋπολογισμό αυτόματης αποστολής) και αναφέρει απευθείας σε αυτόν.
  2. **Γραμματέας** — η διαχειρίστρια των πρακτόρων: σχεδιάζει και εκχωρεί εργασίες, και ως επικοινωνιακή παρέχει φωνητική λειτουργία (φωνητική είσοδος/έξοδος) με ήχο κινηματογραφικής ποιότητας (Kokoro `df_eva`, ταχύτητα 0.9). Είναι επίσης η **διεπαφή επικοινωνίας** μεταξύ του πολυπρακτορικού συστήματος και του ανθρώπου χρήστη. Όταν ενεργοποιείται, οπλίζει αυτόματα την ομάδα της (Κουμπί 1)· όταν απενεργοποιείται, παραμένει σε λειτουργία μια ομάδα **οπλισμένη χειροκίνητα**.
  3. **Προσωρινός κλωνοποίηση** — επιτρέπει στους πράκτορες να πολλαπλασιαστούν προσωρινά για τη διάρκεια μιας εργασίας για να επεξεργάζονται παρόμοιες εργασίες ταυτόχρονα.
  4. **Αρμονικοποίηση & ορχήστρωση** — αρμονικοποιεί/συγχρονίζει είτε τους πράκτορες εντός των εργασιών (χωρίς τη Γραμματέα), είτε, όταν η Γραμματέας είναι ενεργή, οι πράκτορες κατευθύνονται από αυτήν και αρμονικοποιούνται/συγχρονίζονται μαζί της.
- **Orchestration HUD** — τέσσερα ζωντανά πάνελ με μπλε περίγραμμα κάτω από την είσοδο composer: *Ομάδα υπο-πρακτόρων*, *Hermes Γραμματέας (Φωνητική Επικοινωνία)*, *Κλωνοποιημένοι πράκτορες*, και *Αρμονία και φόρτος πρακτόρων*. Τα πάνελ εμφανίζονται μόνο όταν τρέχει μια πραγματική εργασία — χωρίς placeholders επίδειξης.
- **Hermes Γραμματέας** — ένα φωνητικό στρώμα που σας επιτρέπει να μιλάτε στον πράκτορα. Γερμανικό TTS μέσω **Kokoro** (`df_eva`, θηλυκό, ταχύτητα filmreif 0.9), STT μέσω Whisper, και ένας αόρατος (headless) ελεγκτής στάθμης μικροφώνου (χωρίς ορατό παράθυρο τερματικού). Ο πράκτορας μπορεί να αναθέτει υπο-πράκτορες για την εκτέλεση προφορικών αιτημάτων.
- **Ομάδα μάθησης (ζωντανά σκορ)** — μια μπάρα κάτω από το composer εμφανίζει την πρόοδο μάθησης : η επάνω σειρά *Hermes Agent*, *Σχεδιαστής* και *Γραμματέας*, από κάτω οι ειδικοί (έρευνα, κώδικας, ανάλυση, εικόνα, ήχος, σχεδιασμός) σε **το πολύ δύο συμπαγείς σειρές** — ποτέ μια σειρά ανά ειδικό. Κάθε ειδικός έχει το δικό του σκορ, τον δικό του αριθμό αποφάσεων και τη δική του τάση. Εμφανίζονται αποκλειστικά πραγματικές τιμές· χωρίς πραγματική ανάθεση, η μπάρα παραμένει κενή.
- **Επιλογέας μοντέλου** — το αναδιπλούμενο μενού ομαδοποιεί τα μοντέλα Nous, το **OpenRouter** και την κατηγορία **MLX-Runtime nativ** με τα μοντέλα MLX που είναι διαθέσιμα τοπικά στους δίσκους του συστήματος. Η εναλλαγή είναι άμεση και ασφαλής : λειτουργεί πάντα μόνο ένα backend (προστασία RAM στο Mac mini 16 GB), και σε γρήγορη εναλλαγή, η **τελευταία** επιλεγμένη καταχώρηση κερδίζει πάντα· τα καταργημένα φορτία διακόπτονται καθαρά.
- **MLX Runtime Proxy** — ένα τοπικό lazy proxy (`:1240`) που εξυπηρετεί τα Kokoro TTS, Whisper STT, και MLX μοντέλα συνομιλίας ένα τη φορά, ώστε το Mac mini 16 GB να παραμένει εντός ορίων RAM.

> **Σημείωση:** Το MLX runtime, το Γερμανικό Kokoro TTS, και ο φωνητικός αγωγός της Hermes Γραμματέας είναι βελτιστοποιημένα για Apple Silicon (macOS). Δείτε το `plugins/hermes-sekretaerin/` για ρύθμιση.

## Γρήγορη Εγκατάσταση

### Linux, macOS, WSL2, Termux

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

### Windows (εγγενές, PowerShell)

> **Προσοχή:** Τα εγγενή Windows εκτελούν το Hermes χωρίς WSL — το CLI, το gateway, το TUI, και τα εργαλεία λειτουργούν όλα εγγενώς. Αν προτιμάτε να χρησιμοποιήσετε το WSL2, η one-liner εντολή Linux/macOS παραπάνω λειτουργεί και εκεί. Βρήκατε ένα bug; Παρακαλώ [αναφέρετε ζητήματα](https://github.com/NousResearch/hermes-agent/issues).

Εκτελέστε αυτό στο PowerShell:

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Ο εγκαταστάτης αναλαμβάνει τα πάντα: uv, Python 3.11, Node.js, ripgrep, ffmpeg, **και ένα φορητό Git Bash** (MinGit, αποσυσκευασμένο στο `%LOCALAPPDATA%\hermes\git` — δεν απαιτείται δικαιώματα διαχειριστή, πλήρως απομονωμένο από οποιαδήποτε εγκατάσταση συστήματος Git). Το Hermes χρησιμοποιεί αυτό το ενσωματωμένο Git Bash για να εκτελεί εντολές shell.

Αν έχετε ήδη εγκατεστημένο το Git, ο εγκαταστάτης το εντοπίζει και το χρησιμοποιεί αντίθετα. Διαφορετικά, ένα λήψη MinGit ~45MB είναι το μόνο που χρειάζεστε — δεν θα αγγίξει ούτε θα παρέμβει σε οποιοδήποτε Git συστήματος.

> **Android / Termux:** Η δοκιμασμένη χειροκίνητη διαδρομή τεκμηριώνεται στον [οδηγό Termux](https://hermes-agent.nousresearch.com/docs/getting-started/termux). Στο Termux, το Hermes εγκαθιστά ένα επιλεγμένο επιπλέον `.[termux]` επειδή το πλήρες επιπλέον `.[all]` τραβάει επί του παρόντος εξαρτήσεις φωνής μη συμβατές με Android.
>
> **Windows:** Τα εγγενή Windows υποστηρίζονται πλήρως — η PowerShell one-liner παραπάνω εγκαθιστά τα πάντα. Αν προτιμάτε να χρησιμοποιήσετε το WSL2, η εντολή Linux λειτουργεί και εκεί. Η εγγενής εγκατάσταση Windows βρίσκεται στο `%LOCALAPPDATA%\hermes`· το WSL2 εγκαθίσταται στο `~/.hermes` όπως και στο Linux.

## Ρύθμιση Hermes Γραμματέας (Επέκταση SonnerStudio)

Το φωνητικό στρώμα βρίσκεται στο `plugins/hermes-sekretaerin/`:

```bash
bash plugins/hermes-sekretaerin/setup.sh
```

Αυτό εγκαθιστά:
- `mlx-proxy.py` ως launchd daemon (εξυπηρετεί TTS/STT/MLX μοντέλα στο `:1240`)
- `mic-level.py` ως headless LaunchAgent (ελεγκτής στάθμης μικροφώνου, χωρίς παράθυρο τερματικού)
- `kokoro-tts-server.py` (Γερμανικό Kokoro TTS, `df_eva`)

**Μεταγλώττιση Kokoro (μία φορά):** δείτε το `plugins/hermes-sekretaerin/BUILD_kokoro.md`. Απαιτεί τα `cmake`, τις κεφαλίδες `espeak-ng`, και τα υπομοντέλα `ggml`/`highway`.

**Άδεια μικροφώνου:** παραχωρήστε πρόσβαση macOS *System Settings → Privacy & Security → Microphone* στον βοηθό μία φορά.

### Αντιμετώπιση Προβλημάτων

#### Το Windows Defender ή κάποιο antivirus σηματοδοτεί το `uv.exe` ως κακόβουλο λογισμικό

Αν το antivirus σας (Bitdefender, Windows Defender κ.ά.) βάλει σε καραντίνα το `uv.exe` από τον φάκελο `bin` του Hermes (`%LOCALAPPDATA%\hermes\bin\uv.exe`), πρόκειται για **λανθασμένο θετικό (false positive)**. Το αρχείο είναι το `uv` της Astral — ο Rust διαχειριστής πακέτων Python που το Hermes συμπεριλαμβάνει για τη διαχείριση του περιβάλλοντος Python του. Οι μηχανές antivirus βασισμένες σε ML συνήθως σηματοδοτούν μη υπογεγραμμένα δυαδικά Rust που λαμβάνουν και εγκαθιστούν πακέτα.

**Για να επαληθεύσετε ότι το αντίγραφό σας είναι αυθεντικό:**

```powershell
# Εγκατάσταση GitHub CLI αν χρειάζεται
winget install --id GitHub.cli

# Σύνδεση στο GitHub
gh auth login

# Εκτέλεση επαλήθευσης
$uv = "$env:LOCALAPPDATA\hermes\bin\uv.exe"
$ver = (& $uv --version).Split(' ')[1]
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$zip = "$env:TEMP\uv.zip"
Invoke-WebRequest "https://github.com/astral-sh/uv/releases/download/$ver/uv-x86_64-pc-windows-msvc.zip" -OutFile $zip -UseBasicParsing
gh attestation verify $zip --repo astral-sh/uv
Expand-Archive $zip "$env:TEMP\uv_x" -Force
(Get-FileHash "$env:TEMP\uv_x\uv.exe").Hash -eq (Get-FileHash $uv).Hash
```

Αν η επαλήθευση (attestation) εμφανίσει «Verification succeeded» και η τελευταία γραμμή εκτυπώσει `True`, είστε εντάξει.

**Για να βάλετε το Hermes σε λίστα επιτρεπόμενων (whitelist):**

- **Windows Defender:** Εκτελέστε PowerShell ως Admin → `Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\hermes\bin"`
- **Bitdefender:** Προσθέστε μια εξαίρεση στην κονσόλα Bitdefender (Protection > Antivirus > Settings > Manage Exceptions)
- Βάλτε σε λίστα επιτρεπόμενων τον **φάκελο**, όχι το hash αρχείου — το Hermes ενημερώνει το `uv` και το hash αλλάζει σε κάθε έκδοση

Για περισσότερο περιεχόμενο, δείτε τις αναφορές upstream της Astral: [astral-sh/uv#13553](https://github.com/astral-sh/uv/issues/13553), [astral-sh/uv#15011](https://github.com/astral-sh/uv/issues/15011), [astral-sh/uv#10079](https://github.com/astral-sh/uv/issues/10079).

```bash
hermes doctor       # Διάγνωση τυχόν προβλημάτων
```

## Παραλείψτε τη συλλογή API-keys — Nous Portal

Το Hermes λειτουργεί με όποιον πάροχο θέλετε — αυτό δεν αλλάζει. Αλλά αν προτιμάτε να μην συλλέξετε πέντε ξεχωριστά κλειδιά API για το μοντέλο, την αναζήτηση στον ιστό, τη δημιουργία εικόνων, το TTS, και ένα cloud browser, το **[Nous Portal](https://portal.nousresearch.com)** καλύπτει όλα αυτά με μία συνδρομή:

- **300+ μοντέλα** — επιλέξτε οποιοδήποτε από αυτά με `/model <όνομα>`
- **Tool Gateway** — αναζήτηση στον ιστό (Firecrawl), δημιουργία εικόνων (FAL), text-to-speech (OpenAI), cloud browser (Browser Use), όλα δρομολογημένα μέσω της συνδρομής σας. Χωρίς επιπλέον λογαριασμούς.

Μία εντολή από μια φρέσκια εγκατάσταση:

```bash
hermes setup --portal
```

Αυτό σας συνδέει μέσω OAuth, ορίζει το Nous ως πάροχό σας, και ενεργοποιεί το Tool Gateway. Ελέγξτε τι είναι συνδεδεμένο ανά πάσα στιγμή με `hermes portal info`. Πλήρεις λεπτομέρειες στη [σελίδα εγγράφων Tool Gateway](https://hermes-agent.nousresearch.com/docs/user-guide/features/tool-gateway).

Μπορείτε ακόμα να φέρετε τα δικά σας κλειδιά ανά εργαλείο όποτε θέλετε — η πύλη είναι ανά backend, όχι όλα-ή-τίποτα.

## Γρήγορη Αναφορά CLI έναντι Ανταλλαγής Μηνυμάτων

Το Hermes έχει δύο σημεία εισόδου: ξεκινήστε το τερματικό UI με `hermes`, ή εκτελέστε το gateway και μιλήστε του από Telegram, Discord, Slack, WhatsApp, Signal, ή Email. Μόλις μπείτε σε μια συνομιλία, πολλές εντολές slash είναι κοινές και στις δύο διεπαφές.

| Έναρξη νέας συνομιλίας                      | `/new` ή `/reset`                             | `/new` ή `/reset`                                                               |
| Αλλαγή μοντέλου                             | `/model [provider:model]`                     | `/model [provider:model]`                                                        |
| Ορισμός προσωπικότητας                      | `/personality [name]`                         | `/personality [name]`                                                            |
| Επανάληψη ή αναίρεση της τελευταίας στροφής | `/retry`, `/undo`                             | `/retry`, `/undo`                                                                |
| Συμπίεση περιβάλλοντος / έλεγχος χρήσης    | `/compress`, `/usage`, `/insights [--days N]` | `/compress`, `/usage`, `/insights [days]`                                        |

Για τις πλήρεις λίστες εντολών, δείτε τον [οδηγό CLI](https://hermes-agent.nousresearch.com/docs/user-guide/cli) και τον [οδηγό Messaging Gateway](https://hermes-agent.nousresearch.com/docs/user-guide/messaging).

## Μετεγκατάσταση από το OpenClaw

Αν έρχεστε από το OpenClaw, το Hermes μπορεί να εισάγει αυτόματα τις ρυθμίσεις, τις μνήμες, τις δεξιότητες και τα κλειδιά API σας.

**Κατά τη διάρκεια της πρώτης ρύθμισης:** Ο οδηγός ρύθμισης (`hermes setup`) εντοπίζει αυτόματα το `~/.openclaw` και προσφέρει μετεγκατάσταση πριν ξεκινήσει η διαμόρφωση.

**Οποιαδήποτε στιγμή μετά την εγκατάσταση:**

```bash
hermes claw migrate              # Διαδραστική μετεγκατάσταση (πλήρες προεπιλεγμένο)
hermes claw migrate --dry-run    # Προεπισκόπηση του τι θα μετεγκατασταθεί
hermes claw migrate --preset user-data   # Μετεγκατάσταση χωρίς μυστικά
hermes claw migrate --overwrite  # Αντικατάσταση υπαρχουσών διενέξεων
```

Τι εισάγεται:

- **SOUL.md** — αρχείο προσωπικότητας
- **Μνήμες** — καταχωρήσεις MEMORY.md και USER.md
- **Δεξιότητες** — δεξιότητες που δημιούργησε ο χρήστης → `~/.hermes/skills/openclaw-imports/`
- **Λίστα επιτρεπόμενων εντολών** — μοτίβα έγκρισης
- **Ρυθμίσεις ανταλλαγής μηνυμάτων** — διαμορφώσεις πλατφόρμας, επιτρεπόμενοι χρήστες, κατάλογος εργασίας
- **Κλειδιά API** — επιτρεπόμενα μυστικά (Telegram, OpenRouter, OpenAI, Anthropic, ElevenLabs)
- **Πόροι TTS** — αρχεία ήχου χώρου εργασίας
- **Οδηγίες χώρου εργασίας** — AGENTS.md (με `--workspace-target`)

Δείτε `hermes claw migrate --help` για όλες τις επιλογές, ή χρησιμοποιήστε τη δεξιότητα `openclaw-migration` για μια διαδραστική μετεγκατάσταση με καθοδήγηση πράκτορα με προεπισκοπήσεις dry-run.

## Συνεισφορά

Καλωσορίζουμε συνεισφορές! Δείτε τον [Οδηγό Συνεισφοράς](https://hermes-agent.nousresearch.com/docs/developer-guide/contributing) για ρύθμιση ανάπτυξης, στυλ κώδικα, και διαδικασία PR.

Γρήγορη έναρξη για συνεισφέροντες — χρησιμοποιήστε τον τυπικό εγκαταστάτη, μετά εργαστείτε από τον
πλήρη git checkout που δημιουργεί στο `$HERMES_HOME/hermes-agent` (συνήθως
`~/.hermes/hermes-agent`). Αυτό ταιριάζει με τη διάταξη που χρησιμοποιείται από το `hermes update`, το
διαχειριζόμενο venv, τις lazy εξαρτήσεις, το gateway, και τα εργαλεία εγγράφων.

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
cd "${HERMES_HOME:-$HOME/.hermes}/hermes-agent"
uv pip install -e ".[all,dev]"
scripts/run_tests.sh
```

Χειροκίνητη εναλλακτική κλωνοποίησης (για προσωρινά clones/CI όπου σκόπιμα δεν
θέλετε τη διαχειριζόμενη διάταξη εγκατάστασης):

Δημιουργήστε το venv έξω από το δέντρο πηγαίου κώδικα που κλωνοποιήθηκε — ένα venv μέσα στον κατάλογο
από τον οποίο λειτουργεί ο πράκτορας μπορεί να διαγραφεί από μια εντολή σχετικής διαδρομής που εκτελεί ο πράκτορας
εναντίον του δικού του checkout, καταστρέφοντας το τρέχον runtime εν μέσω συνεδρίας.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv venv ~/.hermes/venvs/hermes-dev --python 3.11
source ~/.hermes/venvs/hermes-dev/bin/activate
uv pip install -e ".[all,dev]"
scripts/run_tests.sh
```
