> **Talen:** Deze README is beschikbaar in [Deutsch](README.de.md), [Français](README.fr.md), [Español](README.es.md), [Nederlands](README.nl.md). De desktop-app heeft een ingebouwde taalkiezer (🌐) met deze en meer.

**Een SonnerStudio-fork van [Hermes Agent](https://hermes-agent.nousresearch.com/) door Nous Research** — de zelfverbeterende AI-agent, uitgebreid met een spraakgestuurde **Hermes Secretaresse** en een visuele **Composer-Control-HUD** voor het orkestreren van sub-agenten.

Deze fork voegt toe:

- **Composer Control Buttons** — vier wisselknoppen in de desktop-composer met live statuskleuren (rood = inactief, geel = provisioning, groen = actief) :
  1. **Sub-agenten activeren** — activeert de gespecialiseerde AI-sub-agenten die autonoom deelopdrachten oppakken, elk met hun eigen gespecialiseerde vaardigheden, en continu leren van opdrachten en in de loop van de tijd. Wanneer de Secretaresse **uit** staat, werkt de crew autonoom: zij haalt taken zelf op bij Hermes Agent (lagere parallel-drempel, dubbel eigen verzendbudget) en rapporteert rechtstreeks aan hem.
  2. **Secretaresse** — de beheerder van de agenten: plant en wijst taken toe, en als communicator biedt een spraakmodus (spraakinvoer/-uitvoer) met filmische audiokwaliteit (Kokoro `df_eva`, snelheid 0.9). Zij is tevens de **communicatie-interface** tussen het multi-agentensysteem en de menselijke gebruiker. Als ze wordt ingeschakeld, rust ze automatisch haar crew uit (Knop 1); als ze wordt uitgeschakeld, blijft een **handmatig** uitgeruste crew actief.
  3. **Tijdelijk klonen** — laat agenten zich tijdelijk vermenigvuldigen voor de duur van een taak om soortgelijke taken tegelijkertijd te verwerken.
  4. **Harmonisatie & orkestratie** — harmoniseert/synchroniseert ofwel de agenten binnen de taken (zonder de Secretaresse), of, wanneer de Secretaresse aan staat, worden de agenten door haar aangestuurd en samen met haar geharmoniseerd/gesynchroniseerd.
- **Orchestration HUD** — vier live panelen met blauwe rand onder de composer-invoer: *Sub-agententeam*, *Hermes Secretaresse (Audiocommunicatie)*, *Gekloonde agenten (Cloned Agents)*, en *Harmonisatie & agentbelasting*. Panelen verschijnen alleen wanneer een echte taak draait — geen demoplaatshouders.
- **Hermes Secretaresse** — een spraaklaag waarmee je met de agent kunt praten. Duitse TTS via **Kokoro** (`df_eva`, vrouwelijk, filmische snelheid 0.9), STT via Whisper, en een headless microfoonniveau-monitor (geen zichtbare terminalpopup). De agent kan sub-agenten delegeren om gesproken verzoeken uit te voeren.
- **Lerende crew (live-scores)** — een balk onder de composer toont de leervoortgang : bovenste rij *Hermes Agent*, *Planner* en *Secretaresse*, daaronder de specialisten (onderzoek, code, analyse, beeld, audio, planning) in **hooguit twee compacte rijen** — nooit één rij per specialist. Elke specialist heeft zijn eigen score, eigen beslissingstelling en eigen trend. Alleen echte waarden worden getoond ; zonder echte delegatie blijft de balk leeg.
- **Modelkiezer** — het dropdown-menu groepeert de Nous-modellen, **OpenRouter** en de categorie **MLX-Runtime natief** met de MLX-modellen die lokaal op de schijven van het systeem beschikbaar zijn. Omschakelen is direct en veilig : er draait altijd maar één backend (RAM-bescherming op de 16 GB Mac mini), en bij snel omschakelen wint altijd de **laatst** geselecteerde entry ; achterhaalde ladingen breken netjes af.
- **MLX Runtime Proxy** — een lokale lazy proxy (`:1240`) die de Kokoro TTS, Whisper STT en MLX chatmodellen één voor één bedient, zodat de 16 GB Mac mini binnen de RAM-limieten blijft.

> **Opmerking:** De MLX-runtime, Kokoro Duitse TTS en de Hermes Secretaresse-spraakpijplijn zijn afgestemd op Apple Silicon (macOS). Zie `plugins/hermes-sekretaerin/` voor installatie.

## Snelle installatie

### Linux, macOS, WSL2, Termux

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

### Windows (native, PowerShell)

> **Let op:** Native Windows draait Hermes zonder WSL — CLI, gateway, TUI en tools werken allemaal native. Als je liever WSL2 gebruikt, werkt de Linux/macOS one-liner hierboven daar ook. Een bug gevonden? [Meld issues aan](https://github.com/NousResearch/hermes-agent/issues).

Voer dit uit in PowerShell:

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Het installatieprogramma regelt alles: uv, Python 3.11, Node.js, ripgrep, ffmpeg, **en een draagbare Git Bash** (MinGit, uitgepakt naar `%LOCALAPPDATA%\hermes\git` — geen admin vereist, volledig geïsoleerd van elke systeem-Git-installatie). Hermes gebruikt deze gebundelde Git Bash om shellcommando's uit te voeren.

Als je Git al geïnstalleerd hebt, detecteert het installatieprogramma dit en gebruikt dat in plaats daarvan. Anders is een ~45MB MinGit-download alles wat je nodig hebt — het raakt of verstoort geen enkele systeem-Git.

> **Android / Termux:** Het geteste handmatige pad staat beschreven in de [Termux-gids](https://hermes-agent.nousresearch.com/docs/getting-started/termux). Op Termux installeert Hermes een samengestelde `.[termux]`-extra omdat de volledige `.[all]`-extra momenteel Android-onverenigbare spraakafhankelijkheden binnenhaalt.
>
> **Windows:** Native Windows wordt volledig ondersteund — de PowerShell one-liner hierboven installeert alles. Als je liever WSL2 gebruikt, werkt het Linux-commando daar ook. Native Windows-installatie staat onder `%LOCALAPPDATA%\hermes`; WSL2 installeert onder `~/.hermes` zoals op Linux.

## Hermes Secretaresse-installatie (SonnerStudio-extensie)

De spraaklaag bevindt zich in `plugins/hermes-sekretaerin/`:

```bash
bash plugins/hermes-sekretaerin/setup.sh
```

Dit installeert:
- `mlx-proxy.py` als een launchd-daemon (bedient TTS/STT/MLX-modellen op `:1240`)
- `mic-level.py` als een headless LaunchAgent (microfoonniveau-monitor, geen terminalvenster)
- `kokoro-tts-server.py` (Kokoro Duitse TTS, `df_eva`)

**Bouw Kokoro (eenmalig):** zie `plugins/hermes-sekretaerin/BUILD_kokoro.md`. Vereist `cmake`, `espeak-ng`-headers en de `ggml`/`highway`-submodules.

**Microfoontoestemming:** geef macOS *Systeeminstellingen → Privacy & Beveiliging → Microfoon* eenmalig toegang aan de helper.

Na installatie:

```bash
source ~/.bashrc    # shell herladen (of: source ~/.zshrc)
hermes              # begin met chatten!
```

### Probleemoplossing

#### Windows Defender of antivirus markeert `uv.exe` als malware

Als je antivirus (Bitdefender, Windows Defender, enz.) `uv.exe` uit de Hermes `bin`-map (`%LOCALAPPDATA%\hermes\bin\uv.exe`) in quarantaine plaatst, is dit een **foutpositief**. Het bestand is Astral's `uv` — de Rust Python-pakketbeheerder die Hermes bundelt om zijn Python-omgeving te beheren. Op ML gebaseerde antivirusprogramma's markeren vaak niet-ondertekende Rust-binaire bestanden die pakketten downloaden en installeren.

**Verifieer dat je kopie authentiek is:**

```powershell
# Installeer GitHub CLI indien nodig
winget install --id GitHub.cli

# Log in op GitHub
gh auth login

# Voer verificatie uit
$uv = "$env:LOCALAPPDATA\hermes\bin\uv.exe"
$ver = (& $uv --version).Split(' ')[1]
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
$zip = "$env:TEMP\uv.zip"
Invoke-WebRequest "https://github.com/astral-sh/uv/releases/download/$ver/uv-x86_64-pc-windows-msvc.zip" -OutFile $zip -UseBasicParsing
gh attestation verify $zip --repo astral-sh/uv
Expand-Archive $zip "$env:TEMP\uv_x" -Force
(Get-FileHash "$env:TEMP\uv_x\uv.exe").Hash -eq (Get-FileHash $uv).Hash
```

Als de attestation "Verification succeeded" zegt en de laatste regel `True` afdrukt, ben je klaar.

**Om Hermes op de witte lijst te zetten:**
- **Windows Defender:** Draai PowerShell als Admin → `Add-MpPreference -ExclusionPath "$env:LOCALAPPDATA\hermes\bin"`
- **Bitdefender:** Voeg een uitzondering toe in de Bitdefender-console (Protection > Antivirus > Settings > Manage Exceptions)
- Zet de **map** op de witte lijst, niet de bestandshash — Hermes werkt `uv` bij en de hash verandert elke versie

Voor meer context, zie de upstream Astral-rapporten: [astral-sh/uv#13553](https://github.com/astral-sh/uv/issues/13553), [astral-sh/uv#15011](https://github.com/astral-sh/uv/issues/15011), [astral-sh/uv#10079](https://github.com/astral-sh/uv/issues/10079).

## Sla de API-sleutelverzameling over — Nous Portal

Hermes werkt met elke provider die je wilt — dat verandert niet. Maar als je liever geen vijf aparte API-sleutels verzamelt voor het model, webzoekopdrachten, beeldgeneratie, TTS en een cloudbrowser, dekt **[Nous Portal](https://portal.nousresearch.com)** ze allemaal onder één abonnement:

- **300+ modellen** — kies er elk met `/model <name>`
- **Tool Gateway** — webzoekopdrachten (Firecrawl), beeldgeneratie (FAL), tekst-naar-spraak (OpenAI), cloudbrowser (Browser Use), allemaal via je abonnement gerouteerd. Geen extra accounts.

Eén commando vanaf een verse installatie:

```bash
hermes setup --portal
```

Dit logt je in via OAuth, stelt Nous in als je provider en zet de Tool Gateway aan. Controleer op elk moment wat is aangesloten met `hermes portal info`. Volledige details op de [Tool Gateway-documentatiepagina](https://hermes-agent.nousresearch.com/docs/user-guide/features/tool-gateway).

Je kunt altijd je eigen sleutels per tool meenemen wanneer je wilt — de gateway is per-backend, niet alles-of-niets.

## Migreren vanuit OpenClaw

Als je van OpenClaw komt, kan Hermes automatisch je instellingen, herinneringen, skills en API-sleutels importeren.

**Tijdens de eerste installatie:** De setup-wizard (`hermes setup`) detecteert automatisch `~/.openclaw` en biedt migratie aan voordat de configuratie begint.

**Op elk moment na installatie:**

```bash
hermes claw migrate              # Interactieve migratie (volledige preset)
hermes claw migrate --dry-run    # Voorbeeld van wat gemigreerd zou worden
hermes claw migrate --preset user-data   # Migreer zonder geheimen
hermes claw migrate --overwrite  # Overschrijf bestaande conflicten
```

Wat wordt geïmporteerd:

- **SOUL.md** — persona-bestand
- **Herinneringen** — MEMORY.md- en USER.md-vermeldingen
- **Skills** — door gebruikers gemaakte skills → `~/.hermes/skills/openclaw-imports/`
- **Commandowhitelist** — goedkeuringspatronen
- **Berichteninstellingen** — platformconfigs, toegestane gebruikers, werkmap
- **API-sleutels** — toegestane geheimen (Telegram, OpenRouter, OpenAI, Anthropic, ElevenLabs)
- **TTS-assets** — werkruimte audiobestanden
- **Werkruimte-instructies** — AGENTS.md (met `--workspace-target`)

Zie `hermes claw migrate --help` voor alle opties, of gebruik de `openclaw-migration`-skill voor een interactieve, agent-begeleide migratie met dry-run-voorbeelden.

## Bijdragen

We verwelkomen bijdragen! Zie de [Contributing Guide](https://hermes-agent.nousresearch.com/docs/developer-guide/contributing) voor ontwikkelingssetup, codestijl en het PR-proces.

Snel starten voor bijdragers — gebruik de standaardinstallatie, werk dan vanuit de volledige git-checkout die deze aanmaakt op `$HERMES_HOME/hermes-agent` (meestal `~/.hermes/hermes-agent`). Dit komt overeen met de lay-out die wordt gebruikt door `hermes update`, de beheerde venv, lazy afhankelijkheden, gateway en docs-tooling.

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
cd "${HERMES_HOME:-$HOME/.hermes}/hermes-agent"
uv pip install -e ".[all,dev]"
scripts/run_tests.sh
```

Handmatige clone-fallback (voor wegwerp-clones/CI waarbij je bewust niet de beheerde installatielay-out wilt):

Maak de venv buiten de gekloonde bronboom aan — een venv binnen de map waar de agent vanuit werkt, kan worden gewist door een relatief-padcommando dat de agent uitvoert op zijn eigen checkout, waardoor de draaiende runtime midden in een sessie wordt vernietigd.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
uv venv ~/.hermes/venvs/hermes-dev --python 3.11
source ~/.hermes/venvs/hermes-dev/bin/activate
uv pip install -e ".[all,dev]"
scripts/run_tests.sh
```
